CTA Smokers: aggregate smoking report counts

Exported 2026-11-24 23:58 UTC

Counts of crowdsourced smoking reports on Chicago CTA trains, by train line.

Files
  daily.csv     line, date (YYYY-MM-DD), report_count
  weekly.csv    line, iso_week (YYYY-Www), report_count
  monthly.csv   line, month (YYYY-MM), report_count
  yearly.csv    line, year (YYYY), report_count
  all_time.csv  line, report_count

Days, months, and years use Chicago time (America/Chicago). Weeks are ISO weeks.
A line and period with no row had no reports.

This project is not affiliated with the Chicago Transit Authority. All data is
user-submitted and provided as-is.
